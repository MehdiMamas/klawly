Auto

One switch: Claude picks the model and the helpers, and shows the cost as it goes

Auto

Auto
On by default for new chats (claude.auto.enabled). Replaces the Auto model, the Auto permission level and Auto-Keep. Switched off mid-run, running helpers finish.

Short judgment work: the strongest model alone. Build work: the strongest model plans and reviews, Sonnet helpers build. Mechanical work: free tools or Haiku. A helper that fails twice moves up to the strongest model. See Auto mode. (DL-109, DL-110)

Permissions

Ask Haiku about each request
A small model decides requests that would ask. Credentials, destructive commands and paths outside the workspace keep their card (claude.agent.autoMode.*)
Respect Plan and Bypass
Auto never overrides a chat set to Plan or Bypass permissions
Auto Reviews File Deletions
Off: deleting files always asks. On: Auto may approve a plain delete inside the workspace. A wrong call loses files
Auto Reviews Writes Outside the Workspace
Off: writing outside the workspace always asks. On: Auto may approve it. A wrong call can overwrite files elsewhere on disk
Auto Reviews Agent Browser Pages
Off: opening a page outside this machine always asks. On: Auto may approve it. Localhost never asks
