ESLint for the editor

Runs the ESLint library installed in your workspace and shows its findings as you type. It uses the configuration your project already has, so the editor and the command line agree.

If no local copy is found, the extension falls back to a global install. Nothing is linted until a configuration file exists.

Getting started

  • Install ESLint in the project: npm install --save-dev eslint.
  • Create a configuration: npm init @eslint/config.
  • Open any JavaScript or TypeScript file. Problems appear in the editor and in the Problems panel.

Settings

  • eslint.enable: turn linting on or off for a workspace.
  • eslint.run: lint onType or onSave.
  • eslint.validate: the languages to lint.
  • editor.codeActionsOnSave: add source.fixAll.eslint to fix on save.
