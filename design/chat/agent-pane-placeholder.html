What changed

  • applyDiscount(code) trims and upper-cases the code before it looks it up.
  • totals() returns the discount and the total after it.
  • New discounts.ts holds the codes, and two tests cover a valid and an unknown code.

cart.add({ sku: 'MUG-01', price: 12, quantity: 2 });
cart.applyDiscount(' spring10 '); // true
cart.totals(); // { subtotal: 24, discount: 2.4, total: 21.6 }
